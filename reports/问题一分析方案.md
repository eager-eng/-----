# 问题一分析方案 · 把取消、备降和未知航段纳入可靠性测量

## 1. 研究对象和题目产出

以旅客选择的一个**计划航段**为观测单位，按计划始发机场归属。历史核心期为 **2023 年 1 月至 2025 年 12 月**，使用 BTS Reporting Carrier On-Time Performance 月包。选择 ATL、DEN、DFW、MCO、ORD、PDX、RDU、SFO，覆盖东南、山地、中南部、五大湖及太平洋沿岸，并包含不同规模、承运人集中度和航线结构。FAA 2024 年分类中，PDX、RDU 为中型枢纽，其余六个为大型枢纽。 [赛题原文](../2027_MCM_C_Mock_On_Time_On_Paper.pdf) · [FAA 机场等级](https://www.faa.gov/airports/planning_capacity/passenger_allcargo_stats/passenger/arp-cy2024-commercial-service-enplanements.pdf) · [机场结构与覆盖](../data/audit/airport_candidate_coverage.csv)

交付机场六态审核表、全计划可靠性阶梯图、四项比率及严重中断分项、分母与阈值敏感性表，并记录未知结局、数据覆盖与结果适用范围。

## 2. 航段审计与六态判定

以 BTS 承运人标识、航班号、计划服务日、起讫机场和计划离港时间形成候选航段键，以源月和源行追溯记录。核查重复、缺失关键标识、跨月身份冲突和结局字段矛盾。身份可以确认而结局仍未知的航段计入全计划分母。身份异常单独留档。 [BTS 字段字典](https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FGJ) · [开发期批次](../data/analysis/development/manifest.json) · [2025 年批次](../data/analysis/q3_holdout2025/manifest.json)

| 状态 | 判定 |
| --- | --- |
| $C$ 取消 | 已确认取消。取消优先用于主结局分类，备降过程另列 |
| $V$ 备降且未取消 | 已确认备降且未取消。进一步区分最终是否到达原计划目的地 |
| $T$ 未备降准点 | 已确认未备降抵达，距计划到达时刻晚少于 15 分钟。提前抵达计入 |
| $M_\tau$ 中度延误 | 已确认未备降抵达，$15\le d<\tau$ |
| $L_\tau$ 长延误 | 已确认未备降抵达，$d\ge\tau$ |
| $U$ 未知 | 在原始字段及一致的辅助证据下仍无法判定主结局 |

其中 $d$ 为有符号的到达延误分钟。到达时间空值先依据状态处理。取消或确认未抵达的备降记录具有结构性空值。对已确认抵达但缺延误分钟的航段，先记录抵达事实，再逐个阈值根据可用证据判定。15 分钟准点定义采用 BTS 口径，长延误主阈值取 60 分钟，以 45 和 90 分钟复核。 [14 CFR §234.2 准点定义](https://www.govinfo.gov/content/pkg/CFR-2024-title14-vol4/pdf/CFR-2024-title14-vol4-sec234-2.pdf)

## 3. 唯一主方法与指标

采用**带事件识别界限的非参数经验可靠性曲线**。对机场 $a$，$N_a$ 是全部有效计划航段数，$S_a(t)$ 是已确认未备降、抵达且满足 $d<t$ 的航段数，$U_a(t)$ 是该阈值事件仍无法判定的航段数。绘制确认比例的经验阶梯，并根据未知记录给出界限

$$
R_a(t)\in \left[\frac{S_a(t)}{N_a},\,\frac{S_a(t)+U_a(t)}{N_a}\right].
$$

固定分母让每个阈值对应旅客事前选中一班计划航段的及时抵达比例。只需已核验的计数，即可同时保留取消、备降和未知结局。界限由未知记录对事件的两种极端归类得到。 [Joel L. Horowitz 与 Charles F. Manski，2000，Nonparametric Analysis of Randomized Experiments with Missing Covariate and Outcome Data](https://eml.berkeley.edu/symposia/nsf99/papers/horowitz.pdf)

| 指标 | 定义 |
| --- | --- |
| $R_1$ 全计划未备降准点率 | $n_T/N$，为严格曲线 15 分钟处的确认比例 |
| $R_2$ 已知主结局条件准点率 | $n_T/(N-n_U)$ |
| $R_3$ 未备降抵达条件准点率 | $n_T/n_A$，其中 $n_A=n_T+n_M+n_L$ |
| $R_4$ 最终抵达原计划目的地率 | 已确认最终抵达数除以 $N$，包含确认备降后抵达的航段，并按事件给出上界 |
| $D_\tau$ 严重中断率 | 已确认 $C\cup V\cup L_\tau$ 的航段数除以 $N$，并按事件给出上界 |
| 分项风险 | 取消率、互斥备降率、曾备降过程率、最终抵达且晚至少 60 分钟的比率均以 $N$ 为分母 |

令 $[r_\ell(\tau),r_u(\tau)]$ 为严格可靠性区间，严重中断率的对应区间为 $[1-r_u(\tau),1-r_\ell(\tau)]$。最终抵达的判定包括有独立抵达证据的未知主结局记录。沿用同一准点分子，$R_3-R_1=R_3(n_C+n_V+n_U)/N$。条件分母为零时记录为不可计算。

## 4. 定义敏感性、验收和交接

1. **分母。** 并列报告 $R_1$、$R_2$、$R_3$ 和 $R_3-R_1$。用未舍入的率检查三年汇总与逐月名次，同值并列。对同一批具备有效延误分钟的未备降抵达航段，补报有符号均值和提前抵达计零均值。
2. **阈值。** 在 0–180 分钟的整数网格绘严格经验阶梯，逐对核查相邻阈值的名次变化。以 $d<15$ 和 $d<16$ 检查恰好晚 15 分钟的边界效应。对 $D_{45}$、$D_{60}$、$D_{90}$ 比较风险量级和次序。180 分钟为作图终点，$R_4$ 另从最终抵达事件计数。
3. **备降。** 宽口径允许计入备降后在阈值内抵达的航段，使用其备降后延误字段。最终抵达与延误是否可判定分别审核。严格版与宽版使用同一个计划航段分母。
4. **验收。** 按月逐场核对六态及事件计数，检查分母恒等式、曲线单调性、15 分钟锚点、严重中断互补区间和原始月包的边界记录。三年结果报告注明 288 个机场月和独立复算数。
5. **后续使用。** 问题二使用相同的总分母与结局定义调整航班构成。问题三、四沿用严重中断标签和未知标记。问题五把取消、备降、长延误与最终抵达表述为各自的航段风险。BTS 报告覆盖、行程联结、取消公告及改签信息决定这些指标的适用范围。 [Bratu 与 Barnhart，2005，An Analysis of Passenger Delays Using Flight Operations and Passenger Booking Data](https://doi.org/10.2514/atcq.13.1.1)
